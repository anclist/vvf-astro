# Victoria Venezuela Foundation - Proposal

## Overview
Build a mobile-friendly website for the Victoria Venezuela Foundation using Astro, with CMS capabilities for dynamic content and reusable components.

## Tech Stack
- **Framework**: Astro 5.x with React components
- **CMS**: Content Collections (Markdown/MDX) or integration with Headless CMS (Contentful, Sanity, or Strapi)
- **Design System**: Custom component library with Catalyst components
- **Styling**: CSS Variables + Tailwind CSS for responsive design
- **React Integration**: Catalyst UI components for interactive elements

## Requirements
1. Mobile-first responsive design
2. CMS for content management (events, news, team, etc.)
3. Reusable component patterns
4. React components for interactive features
5. Data-driven pages for dynamic content

## Approach
- Use Astro's Content Collections for structured data
- Build catalog-pattern components for repeatable items
- Implement design system with themable CSS variables
- Use React hybrid mode for interactive catalyst components
- Optimize for performance and accessibility

- Define CMS schema and content model
- Create initial project structure
- Build core component library
